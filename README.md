# Java Core Portfolio

A collection of Java Core exercises and projects created to strengthen my programming skills and build a portfolio.

## Technologies

- Java 21
- Git and GitHub
- Spring Tool Suite (Eclipse-based IDE)

## Topics

- Object-oriented programming
- Classes and objects
- Collections and generics
- Exception handling
- File I/O
- Unit testing with JUnit

## Current Project

The project currently contains a basic Java application. More exercises and projects will be added as I progress.

## Getting Started

1. Install JDK 21 or a compatible version.
2. Clone this repository.
3. Import the project into your Java IDE.
4. Run `Main.java` as a Java application.

## Goal

To practise Java development, improve code quality, and progressively build practical projects.
