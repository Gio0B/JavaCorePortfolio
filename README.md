# Java Core Portfolio

A collection of Java Core exercises and practical projects developed to strengthen programming skills and demonstrate knowledge of Java fundamentals and object-oriented programming.

## Technologies

- Java 21
- Git and GitHub
- Spring Tool Suite (Eclipse-based IDE)

## Topics Covered

- Java fundamentals
- Object-Oriented Programming (OOP)
- Classes, objects and encapsulation
- Methods and static methods
- Arrays and loops
- ArrayList and collections
- Data validation and exception handling
- Immutable objects
- Defensive copying
- Basic algorithms and problem solving

## Projects and Exercises

| Project | Description |
|---|---|
| FizzBuzz | Classic FizzBuzz exercise using loops and conditional statements. |
| NumberAnalyzer | Number analysis, even number checking, digit counting and digit summation. |
| PalindromeChecker | Checks whether a word is a palindrome, ignoring letter case. |
| ArrayAnalyzer | Finds minimum and maximum values, calculates averages and counts occurrences in arrays. |
| BankAccount | Bank account simulation with balance management, deposits, withdrawals and input validation. |
| StudentManager | Student management using ArrayList and collection operations. |
| ContactManager | Contact management with searching, updating, validation and immutable Contact objects. |
| InventoryManager | Inventory management with product creation, searching, updating, removal and inventory value calculation. |

## Getting Started

### Requirements

- JDK 21 or compatible version
- Java IDE (Spring Tool Suite, Eclipse or IntelliJ IDEA)

### Running the project

1. Clone the repository:

   ```bash
   git clone https://github.com/Gio0B/JavaCorePortfolio.git
   ```

2. Import the project into your Java IDE.

3. Run `Main.java` as a Java application.

The `Main` class contains manual tests and examples demonstrating the functionality of the implemented exercises.

## Testing

The current project uses manual tests through the `Main` class to verify expected behavior, input validation and exception handling.

Automated testing with JUnit is planned for a future development stage.
